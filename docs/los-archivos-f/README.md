# Los Archivos F - material de organización

`entrega/` contiene los PDF revisados para imprimir y la guía privada de soluciones. No copiar esta carpeta al directorio public del sitio.

Las fuentes de las pruebas están en `fuentes/` como referencia de geometría y claves. Fueron creadas en el workspace de Detectives; no son un comando de build del sitio.

Los códigos PRUEBA y PRUEBA1 a PRUEBA20 habilitan partidas independientes desde cero en su primer uso. Las tarjetas QR de familias conservan sus códigos originales.
